# StudentHub Portal

## 📖 Project Description
StudentHub is a dynamic, semester-long web portal designed to manage student registrations, user profiles, and campus events. It serves as a centralized platform connecting students with campus activities and providing administrators with robust management tools. This project is developed as part of the Web Development Frameworks (ITUE203) course.

## 👥 User Roles & Permissions
* **Student:** Can register, log in, manage their personal profile, view upcoming campus events, and access study resources.
* **Admin:** Can manage student records (CRUD operations), upload and manage event posters, and view system analytics via a dedicated dashboard.

## 🧩 Key Modules
1. **Authentication Module:** Secure Login and Registration.
2. **Student Management Module:** Admin controls for searching, filtering, and modifying student records.
3. **Event Management Module:** Event creation, poster uploads, and a public-facing event gallery.
4. **Interactive UI Module:** Dynamic DOM manipulation, theme switching, and live feed updates.
